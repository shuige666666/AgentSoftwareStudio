# 前置基线实施记录（2026-09-23）

## 已实现

- 新增显式选择的 `url-shortener-behavior-v1` 与 `poll-system-behavior-v1`，在需求中固定 HTTP 路径、字段、状态码和投票身份字段。原有六案例默认集合保持不变。报告记录需求文本 SHA-256、Git 提交及工作区指纹。
- 在独立 Docker 容器中启动生成项目，通过平台代码发 HTTP 请求判卷；记录每项行为的响应证据，并区分通过、失败、未运行和环境异常。工作流抛异常时尽量保留项目路径与模型用量，并对已生成产物继续判卷。
- 百炼缓存命中 token 从 `usage.prompt_tokens_details.cached_tokens` 读取，按实际模型分别记录命中、未命中、输出、调用和失败次数；保留 DeepSeek 原有缓存字段支持。报告保留停止原因、构建测试摘要和原有平台指标。完整工作流成功率按平台与独立判卷同时通过计算。
- 修复工具返回不可修改文件列表后，修复回滚清空列表导致的 `UnsupportedOperationException`。

## 实际验证

固定 HTTP 夹具测试覆盖两种契约及重复投票失败；修复回滚、报告汇总、缓存字段和用量分模型测试均通过。真实生成使用 `qwen3.7-flash-2026-07-15` 与 `qwen3.7-max-2026-05-20`，两个模型均有成功响应，因此本次没有证据表明其已下架。一次 Flash 测试生成调用在 240 秒后超时，报告分类为 `TIMEOUT`。

两个真实生成产物的 Docker 外部复判各重复执行，结果一致：投票项目八项行为全部通过；短链项目创建响应为 `{"shortCode":"...","originalUrl":null}`，不符合固定的 `code` 和 `originalUrl` 契约，判卷失败。对应记录见 `benchmark-results/behavior-recheck-poll-system-behavior-v1-2026-09-23T11-54-07.108691700Z.json` 和 `benchmark-results/behavior-recheck-url-shortener-behavior-v1-2026-09-23T11-53-29.567203400Z.json`。

修复异常后又运行一次完整短链生成，记录在 `benchmark-results/benchmark-2026-09-23T12-05-42.060935200Z.json`：平台构建与自身测试通过，外部行为失败，属于假成功；项目在 `ai_generated_projects/URL_Shortener_Service_MVP_20260923_200607`。该文件的完整工作流成功率在运行后按修正口径从 1.0 校正为 0.0，其余原始结果未改。早期运行的 `benchmark-results/benchmark-2026-09-23T11-28-45.312857600Z.json` 保留了旧异常作为排查证据。

随后对 `poll-system-behavior-v1` 只补跑一次完整 smoke，报告为 `benchmark-results/benchmark-2026-09-23T12-29-31.002785700Z.json`，产物为 `ai_generated_projects/在线投票系统_MVP_20260923_202956`。工作流正常结束并保留路径与失败分类；45 次模型调用均成功，项目最终构建和自身测试通过，但平台最终契约门禁因 `NOT_FOUND_EXCEPTION_MAPPING` 阻断，停止原因为 `REGRESSION`。独立 HTTP 判卷失败：创建投票与初始结果通过，投票请求返回 `400 Invalid option: null`，后续计票保持 0。该次平台成功数和完整工作流成功率均为 0。

## 限制和下一步

目前报告提供按模型区分的 token 用量与缓存命中，尚无单次任务的账户实际人民币扣费。用户人工核对此前调用的日粒度账单，观察到合计约 1.69 元；该金额不是任何单个案例的费用，也不包含本段后补投票 smoke 的可核定费用。供应商价格随模型、上下文档位、缓存和账户优惠变化，不能把汇总 token 简单当成账单费用。两例均已有完整工作流报告及可复查的行为失败证据，前置基线可用于阶段一对照；比较费用时需补入同期实际账单或明确版本化单价假设，不能将本次小样本写成质量提升结论。
